# راهنمای بکسی

بکسی از یک پروژهٔ دسکتاپ دانشگاهی به یک PWA فارسی و واکنش‌گرا بازسازی شده است. پنل مسافر، راننده و همکاران روی موبایل و دسکتاپ در یک برنامه در دسترس‌اند.

## اجرا

Docker Desktop را اجرا کنید و داخل پوشهٔ پروژه بزنید:

```sh
docker compose up --build -d
```

سپس [localhost:8080](http://localhost:8080) را باز کنید. دیتابیس، API و رابط کاربری همراه حساب‌ها و مدارک کاملاً ساختگی آماده می‌شوند. اجرای اول برای دریافت وابستگی‌ها به اینترنت نیاز دارد.

با دکمهٔ «ورود با حساب نمونه» می‌توانید نقش انتخاب‌شده را امتحان کنید. حساب مسافر `09120000010` و راننده `09120000030` است. برای سرویس بانوان، مسافر `09120000020` و راننده `09120000040` را استفاده کنید. مدیر نمونه کد `9001` و رمز `BaxiDemo!2026` دارد. این اطلاعات فقط برای دموی محلی هستند.

اگر نسخهٔ PWA قبلی را با همین دیتابیس دارید، پیش از ارتقا [مهاجرت افزایشی](database.md#upgrading-an-existing-pwa-demo) را اجرا کنید؛ نیازی به حذف داده‌ها نیست.

برای دیدن یک سفر کامل، مسافر و راننده را در دو پروفایل مرورگر یا پنجرهٔ خصوصی باز کنید: درخواست سفر، شروع کار راننده، پذیرش، شروع سفر، پایان و تسویه، سپس امتیازدهی. همهٔ مبالغ در رابط **تومان** هستند؛ API و دیتابیس مبالغ را به ریال نگه می‌دارند. مبالغ قدیمیِ دارای کسری تومان با یک رقم اعشار نمایش داده می‌شوند.

## گالری راننده و منابع انسانی

در README اصلی، دو راهنمای تصویری مستقل با حالت‌های مختلف برنامه قرار دارد:

- [تجربهٔ راننده](../README.md#the-driver-experience): ثبت‌نام و چهار مدرک، انتظار بررسی و رد، خارج و داخل سرویس، موقعیت تهران، پیشنهاد سفر، پذیرش، سفر فعال، رسید، امتیاز، جزئیات کرایه، کمبود موجودی و برداشت آزمایشی.
- [تجربهٔ HR](../README.md#the-hr-experience): صف پرونده‌ها، بررسی مدارک روی دسکتاپ و موبایل، تأیید و رد با دلیل، تفاوت دسترسی مدیر و کارشناس، گزارش درآمد، حقوق واحدها، گزارش بدون داده و فرم همکار جدید.

تصاویر از اجرای واقعی نسخهٔ محلی با حساب‌ها و مدارک کاملاً ساختگی ثبت شده‌اند. [فهرست تصاویر و روش بازتولید](screenshots/README.md) جزئیات هر وضعیت را توضیح می‌دهد.

## قیمت پیش از درخواست

تعرفه‌ها نمونه‌اند و ادعای قیمت واقعی بازار ندارند:

- **بکسی و بانوان:** ورودی ۲۰٬۰۰۰، هر کیلومتر ۶٬۰۰۰ و حداقل کرایهٔ ۴۰٬۰۰۰ تومان.
- **بسته:** ورودی ۱۵٬۰۰۰، هر کیلومتر ۴٬۰۰۰ و حداقل کرایهٔ ۳۰٬۰۰۰ تومان؛ حداکثر وزن ۲۰ کیلوگرم.
- **بار شهری:** ورودی ۶۰٬۰۰۰، هر کیلومتر ۱۲٬۰۰۰ و حداقل کرایهٔ ۱۰۰٬۰۰۰ تومان؛ حداکثر وزن ۲۰۰۰ کیلوگرم و محدود به ظرفیت وسیله.

قیمت نهایی و ریز محاسبه پیش از درخواست نمایش داده می‌شوند. پیشنهاد قیمت پنج دقیقه اعتبار دارد؛ پس از انقضا، قیمت تازه باید دوباره تأیید شود. مبلغ، کمیسیون و خالص راننده هنگام ثبت ثابت می‌شوند و تسویه از همان اعداد استفاده می‌کند. رفت‌وبرگشت مسافری دو برابر کرایهٔ گرد‌شدهٔ یک‌طرفه است. جزئیات ضرایب وزن، گردکردن و حفظ سوابق در [سیاست قیمت‌گذاری](pricing.fa.md) آمده است.

## طراحی و نصب

طراحی جدید با پس‌زمینهٔ روشن، بنفش محدود، فونت وزیرمتن، فرم‌های خوانا و ناوبری پایین صفحه در موبایل ساخته شده است. جریان سفر به انتخاب مرحله‌ای روی نقشه، مقایسهٔ قیمت سرویس‌ها، روش پرداخت مشخص، نمایش راننده و وسیله و رسید همراه امتیاز تبدیل شده است. [بررسی UX و دلیل تصمیم‌ها](ux-review.fa.md) و تصاویر اجرای واقعی کنار کد قرار دارند.

در Chrome و Edge گزینهٔ نصب برنامه را انتخاب کنید. در iPhone صفحه را با Safari باز کنید و از اشتراک‌گذاری «Add to Home Screen» را بزنید. روی دامنهٔ واقعی، HTTPS لازم است؛ localhost برای آزمایش محلی مناسب است.

پوستهٔ برنامه پس از اولین بارگذاری آنلاین، آفلاین هم باز می‌شود. ثبت سفر، تسویه، ورود و دریافت اطلاعات تازه به اتصال نیاز دارند. داده‌های حساب و مدارک در کش PWA ذخیره نمی‌شوند؛ پس از بارگذاری مجددِ آفلاین، اطلاعات خصوصی حساب نمایش داده نمی‌شود.

## محدودهٔ نسخه

چهار سرویس، ثبت‌نام، بررسی مدارک راننده، پذیرش و چرخهٔ سفر، کیف پول آزمایشی، امتیازدهی، تاریخچه، ساخت همکار و ۲۰ گزارش مدیریتی پیاده شده‌اند.

انتخاب مبدأ و مقصد روی نقشهٔ واقعی انجام می‌شود و سرویس فقط داخل محدودهٔ شهر تهران فعال است. خط اتصال دو نقطه، فاصلهٔ مستقیم است؛ مسیریابی خیابانی و ETA ندارد. کرایه بر اساس فاصلهٔ مستقیم است. کد ورود روی صفحه نمایش داده می‌شود و پیامک ارسال نمی‌شود. پرداخت و برداشت شبیه‌سازی‌اند و هیچ پول واقعی جابه‌جا نمی‌شود. هزینهٔ بیمه دریافت نمی‌شود و پوشش بیمهٔ واقعی وجود ندارد؛ ارزش اظهارشده صرفاً اطلاعات حمل است. این نسخه برای نمایش و توسعهٔ آموزشی آماده شده؛ اتصال به سرویس‌های واقعی، نگهداری نشست مشترک، بررسی هویت واقعی و استقرار عمومی کار مستقلی می‌خواهد.

پروژهٔ اصلی کار نوید، سجاد و آرشام در درس پایگاه دادهٔ دانشگاه بوعلی سینا بوده است. بازسازی جدید از اثر دانشگاهی اصلی متمایز ثبت شده و تاریخچه و آثار طراحی قبلی حفظ شده‌اند. سهم دقیق افراد و وضعیت ابطال کلیدهای قدیمی معلوم نیست و ادعایی دربارهٔ آن‌ها نشده است.
